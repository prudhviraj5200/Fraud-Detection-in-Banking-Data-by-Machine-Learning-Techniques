This project is a Machine Learning-based fraud detection system designed to identify fraudulent banking transactions. The system preprocesses transaction data, trains multiple machine learning models, evaluates their performance, and predicts whether new transactions are FRAUD or NORMAL.

**✨ Features**
    Upload banking transaction datasets
    Data preprocessing and normalization
    Fraud vs. normal transaction analysis
    Train multiple ML models
    Compare model performance
    Evaluate using:
    Accuracy
    Precision
    Recall
    F1-Score
    Predict new transactions as FRAUD or NORMAL
    Simple Tkinter-based GUI
**🤖 Machine Learning Algorithms**

The project implements:

    Logistic Regression
    Decision Tree
    Naive Bayes
    Support Vector Machine (SVM)
    Random Forest
    AdaBoost
    Multi-Layer Perceptron (MLP)
